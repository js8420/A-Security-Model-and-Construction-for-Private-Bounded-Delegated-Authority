WHERE THE DISPERSION COMES FROM: GRINDING, MEASURED
==============================================================================
  Same circuit, same rate, 24 interleaved pairs. Only the grinding
  bits differ. Both settings are below the rate this circuit needs to
  verify, so neither proof is accepted (true); the timing is the point.

  grinding bits                min        q1    median        q3     q3-q1
  ---------------------- --------- --------- --------- --------- ---------
  0                        2424.20   2434.73   2440.61   2490.61     55.87
  20                       2797.72   3772.61   5278.72   6908.88   3136.27

  median difference 2838.11 ms, spread difference 3080.39 ms.
  A geometric search over 2^20 hashes has a mean and a standard
  deviation of the same order, so if grinding is the source these two
  differences should be comparable and the 0-bit row should be tight.

  The smallest proof measured here is 2789121 bytes at 28 provable bits,
  which is 21.3 blobs. No setting in this sweep brings a proof of this
  circuit within one block of call data: the opening proof dominates and
  it shrinks only with the query count, which is what soundness buys.
  A backend meeting a settlement domain's budget has to replace the
  opening argument, not tune it.
